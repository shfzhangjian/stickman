# 火柴人游戏精灵动作预览器

这是一个无需安装、没有外部图片依赖的纯 HTML/CSS/JavaScript 示例项目。角色、场景与反馈效果全部使用 Canvas 2D 实时绘制。动画采用“关键姿势分镜 + 过渡帧”的制作方式，控制点隐藏在简洁的火柴人轮廓中。

## 运行方式

最简单的方式：直接双击 `index.html`，使用现代浏览器打开。

也可以在本目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 已实现内容

- 13 类动作：待机、行走、跑步、急停、跳跃、攀爬、攀爬下箱、箱顶路线、直拳、侧踢、受击、倒地/起身、胜利
- 隐藏式身体控制点：骨盆、脊柱、胸腔、颈部、头部，以及左右肩/肘/腕/手、髋/膝/踝/脚尖
- 侧视图中肩髋基本合并，最终画面只保留头、躯干线、双臂和双腿
- 头部使用右侧面眼睛与鼻部轮廓明确朝向，远侧肢体先绘制，跑动和格斗动作使用实心握拳
- 跑动与格斗腿部使用侧面双骨骼膝关节约束：脚踝保持分镜轨迹，膝盖统一朝角色面向方向弯曲
- 跑步包含触地、下沉、经过和腾空八阶段循环，并保留独立急停动作
- 跑动时躯干整体朝前倾斜，手臂屈肘在胸前与腰后快速交替，后腿蹬地推动重心前移
- 原地跳跃使用 12 个独立侧面关键姿势：站立准备、全身下沉、最大蓄力、短暂停顿、伸髋伸膝、脚尖离地、垂直上升、最高点、寻找落点、双脚接触、深屈膝吸震、缓慢恢复；整个动作没有水平位移
- 最大蓄力时骨盆压低到离地约 22 像素，并延长最低点停留；跳跃高度随蓄力深度加强，落地后再次回到接近相同的低位吸收冲击
- 跳跃采用分阶段速度曲线：蓄力逐渐加速、蹬地爆发、上升减速、下落加速、冲击急减速、恢复缓出；头部视线与手臂前后摆动会同步变化
- 攀爬会自动选择木箱目标，依次表现接近、抓住箱沿、踩箱、手拉脚蹬、重心转移和站上箱顶
- 攀爬使用固定长度的上臂、前臂、大腿和小腿，由手脚接触点反算肘膝位置，身体重心随攀爬阶段移动
- 攀爬下箱从箱顶转向箱体，双手抓沿、骨盆下沉、脚寻找支点，再稳定落回地面；角色朝向会随左右侧攀爬镜像
- 箱顶路线支持 1–5 个连续木箱，自动演示“左端爬上、箱顶行走、箱顶跑步、右端转身、攀爬下来”的完整过程
- 直拳和侧踢包含下蹲、收腰、双手护头、后腿蹬地、命中停顿与回防
- 播放与暂停、0.25×–2.00× 速度调节、1–5 个路线木箱、循环开关
- 沙袋、木箱、敌人假人三种受击目标
- 直拳与侧踢命中时的闪白、抖动、击退、粒子和冲击环
- 跳跃落地与倒地时的尘土、地面冲击环和画面震动
- 角色受击时的变色、位移、粒子和画面震动
- 点击场景目标即可切换受击对象
- 自适应桌面和移动端尺寸

## 操作

- 点击左侧动作按钮或移动端下拉框切换动作。
- 使用底部控件调整播放状态、速度、循环和受击目标。
- 点击沙袋、木箱或敌人假人可直接选中它。
- 空格键可播放/暂停；数字键 `1`–`9` 可快速切换前九个动作。

## 扩展动作

动作定义位于 `index.html` 中的 `ACTIONS` 对象。每个动作由时长和一组关键帧组成；关键帧可以调整身体根节点、分段躯干、肩髋宽度、四肢角度与压缩比例。新增动作后，界面按钮和下拉选项会自动生成。

可用的姿势字段包括：

- `rootX`、`rootY`：角色整体位移
- `torso`、`pelvisTilt`：整体前倾与骨盆倾角
- `spineBend`、`chestBend`、`headTilt`：脊柱、胸腔与头部的分段角度
- `shoulderSpan`、`hipSpan`：肩宽与髋宽系数
- `leftUpperArm`、`leftLowerArm`、`leftHand`：左上臂、前臂与手部角度
- `rightUpperArm`、`rightLowerArm`、`rightHand`：右上臂、前臂与手部角度
- `leftUpperLeg`、`leftLowerLeg`、`leftFoot`：左大腿、小腿与脚部角度
- `rightUpperLeg`、`rightLowerLeg`、`rightFoot`：右大腿、小腿与脚部角度
- `squash`：躯干压缩比例

角度使用弧度，Canvas 坐标系中 `0` 指向右侧，`Math.PI / 2` 指向下方。
